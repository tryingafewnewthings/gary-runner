Technical and security notes

Network calls are limited to https://api.github.com. The token is used solely in an Authorization header and is never written to the repository. Installation uses a single new Git commit and a non-force update of the main branch.

The skill is a source repository asset. ChatGPT Plus Projects do not automatically execute repository Skills. Upload SKILL.md as a Project source if you want it to guide image generation in ordinary chats.

Once installed, you can delete this standalone installer HTML from your repository to keep the public site tidy. Deleting it does not affect the installed skill.
