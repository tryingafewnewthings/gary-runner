Connect Visual Studio to the game

One-time, safe installer. This tool reads your current published game files and prepares replacement copies. It does not write to GitHub or affect your playable game until you upload them.

1. Prepare the update

Open this page on the same GitHub Pages site as your game, then tap Prepare. It checks the original code, current config, and JavaScript syntax before allowing any downloads.

Not started.

No files changed.

2. Download the two replacements

These are full files, not shortened snippets. Both downloads are necessary: index.html updates the game.js cache version so Safari fetches the new code.

3. Publish to GitHub

  1. Keep a working copy or a GitHub commit to revert to.
  2. Replace game.js and index.html in the root of your repository with these new files.
  3. Wait for GitHub Pages to deploy, then open the game in a new Safari tab.
  4. Use ?rain=1 on your game URL to test a faster storm. When shutter phase begins, shops close one by one using the studio coordinates.

Afterwards: edit shops in gary-visual-studio-v1.1.html, press Export game settings, and replace gary-game-config.json in the repo. The game reads the JSON when opened. Other scene objects are not connected yet.

Safety: this does not overwrite game-data.js or art. The bridge reads the published config once per game-page load. It doesn't commit changes automatically, and it refuses to install again if the bridge is already present.
